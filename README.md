# Contador de Nomes em Python

Este projeto é um programa simples em Python que permite ao usuário inserir vários nomes e, em seguida, contar quantas vezes um nome específico foi digitado.  

## ⚙️ Funcionalidades

- Permite ao usuário inserir nomes repetidamente.  
- Finaliza a entrada quando o usuário digita "sair".  
- Permite buscar um nome específico.  
- Conta e exibe quantas vezes o nome foi digitado.  

## 🛠️ Tecnologias Utilizadas

- Python 3
